Tentang

Kebanyakan proyek saya berawal dari kebutuhan sendiri atau kebutuhan teman di kampus. Aplikasi presensi KKN hanya tersedia untuk Android, jadi saya membuat versi iOS-nya. Menguji fitur GPS di iPhone dari laptop Windows ternyata merepotkan, jadi saya menulis Lokasi.

Sehari-hari saya menulis Python dan TypeScript. Saya lebih suka menuntaskan satu proyek sampai benar-benar dipakai daripada memulai banyak purwarupa.

Proyek

Perkakas yang saya bangun dan masih saya pakai. Visual di setiap proyek adalah ilustrasi, bukan tangkapan layar.

Lokasi

Dipakai · 2026

Aplikasi desktop untuk menyimulasikan lokasi iPhone dari laptop Windows saat menguji fitur yang bergantung pada GPS. Terowongan dan sesi DVT dinyalakan sendiri oleh aplikasi, tanpa langkah manual di terminal.

Kendalinya joystick empat kecepatan, klik peta, dan masukan koordinat langsung. Label hanya diperbarui saat digit yang terlihat berubah, dan gelung gerak berhenti saat joystick diam, sehingga CPU tidak terpakai ketika aplikasi menganggur.

Python · Tkinter · pymobiledevice3 · tkintermapview

LKH KKN untuk iOS

Selesai · 2026

Versi iOS dari aplikasi presensi mahasiswa KKN yang semula hanya tersedia di Android. Verifikasi wajah berjalan sepenuhnya di perangkat memakai MobileFaceNet. Wajah dideteksi dari pratinjau kamera, dipotong dan diluruskan dari foto resolusi penuh, lalu diubah menjadi vektor 192 dimensi yang dibandingkan dengan data pendaftaran.

Temuan keamanan

Server ternyata menerima begitu saja nilai yang dikirim aplikasi, termasuk informasi perangkat, koordinat, dan hasil verifikasi wajah. Akibatnya, presensi dapat dipalsukan lewat proksi intersepsi tanpa menyentuh pengenalan wajahnya sama sekali.

Temuan ini saya susun menjadi laporan dan sampaikan lebih dahulu secara tertutup kepada pengelola sistem kampus.

React Native · Expo · TypeScript · VisionCamera · TensorFlow Lite

Pemeriksa naskah PKTI

Dikerjakan · 2026

Mahasiswa mengunggah proposal atau skripsi dalam bentuk DOCX, lalu sistem memeriksanya terhadap Pedoman Karya Tulis Ilmiah UIN Alauddin Makassar pada tiga lapis: format dokumen, ragam bahasa, dan kelengkapan isi.

Pemeriksaan dilakukan langsung pada struktur berkas Word, sehingga tata letak paragraf dapat diperiksa tanpa merusak medan sitasi Mendeley atau Zotero di dalam naskah.

Python · OOXML · analisis dokumen

Pipeline korpus penelitian

Selesai · 2026

Alur pengumpulan teks publik dari Facebook, Instagram, X, dan Google News sebagai bahan penelitian. Setiap dokumen dibawa bersama asal-usulnya: URL, platform, tanggal, penanda unggahan, kode pengambilan, log, dan catatan setiap transformasi.

Datanya dicantumkan dalam naskah dan harus dapat ditelusuri ulang. Karena itu hanya data publik yang diambil, sesuai ketentuan platform, dan identitas pengguna tidak ikut disimpan.
